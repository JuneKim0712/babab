⚡ PriceOracle settings

Keys are stored locally in chrome.storage.local and only ever sent to their own API from the extension's background service worker.

context.dev API key

Used to extract pricing signals from the Amazon product page. A working default key is pre-filled; replace it with your own any time. Responses are cached for 24 hours per ASIN to save credits.

Gemini API key optional

Enables live market-sentiment and discount-probability forecasts from Gemini. Without it PriceOracle runs in Prediction Simulation Mode (historical-volatility and seasonal-discount heuristics), so everything works immediately. Get a key at Google AI Studio.
